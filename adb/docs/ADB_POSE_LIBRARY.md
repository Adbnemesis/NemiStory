# ADB Pose Library

## 1. Overview & Pose Architecture

The ADB pose library defines standardized skeletal and transform configurations for the ADB character rig. Every pose is designed around human weight distribution, controlled asymmetry, and natural storytime performance.

---

## 2. Relaxed & Baseline Poses

| Pose ID | Staging Description | Anatomical Keypoints |
|---|---|---|
| `relaxed_standing` | Default baseline posture | Shoulders relaxed, spine straight, arms hanging easily at sides with soft elbow curve, neutral head. |
| `weight_left` | Casual standing with weight shifted | Pelvis drops slightly right; left hip bears weight; left shoulder lowers, right shoulder rises; relaxed cool lean. |
| `weight_right` | Counter-lean standing | Weight on right leg; torso tilts slightly counter; left arm bent slightly at waist. |
| `casual_slouch` | Relaxed introspective lean | Torso curved gently backward, shoulders dropped, head slightly forward, hands in pockets. |
| `seated_chair` | Seated at desk or studio chair | Hips angled forward, feet grounded on floor, forearms resting naturally on table or thighs. |
| `seated_slump` | Deep comedy/exhausted slump | Lower spine rounded into chair back, head tilted back, arms dangling over chair armrests. |

## 3. Conversational Poses

| Pose ID | Staging Description | Anatomical Keypoints |
|---|---|---|
| `explaining` | Standard active narrative pose | Right arm raised to chest level with open palm; left hand resting at hip; head tilted +4°. |
| `pointing_emphasis` | Directing attention to doodle/prop | Dominant arm extended outward with clean index finger point; body angled toward target; gaze locked on camera. |
| `shrug_open` | "Who knows?" / "Not my fault" | Both shoulders elevated; both elbows tucked to ribs with forearms extended outward, palms up; head tilted. |
| `open_palms` | Honest confession / vulnerability | Both hands raised to mid-chest, fingers relaxed and open toward viewer; torso leaning slightly forward. |
| `hand_near_face` | Contemplative thought | Index finger or knuckle resting gently under jawline/chin; head tilted toward hand; thoughtful gaze. |
| `hand_to_chest` | Sincere personal statement | Right hand placed flat or cupped over heart; soft shoulder drop; warm eye contact. |
| `one_hand_gesture` | Casual commentary | One forearm lifted with relaxed wrist flick; other hand resting calmly at waist. |
| `both_hand_explain` | Elaborate concept demonstration | Both hands actively gesturing in front of chest, framing an imaginary shape. |

## 4. Emotional Poses

| Pose ID | Staging Description | Anatomical Keypoints |
|---|---|---|
| `happy_warm` | Gentle contentment / agreement | Torso upright, soft head tilt, subtle shoulder sway, warm eye contact. |
| `excited_burst` | Animated passion for topic | Torso lunges slightly forward, both hands energized, head alert, sparkle eyes. |
| `surprised_snap` | Sudden unexpected revelation | Torso recoils backward, shoulders snap up, hands pull back toward ribs, wide eyes. |
| `embarrassed_disarmed`| Cute fluster when caught off guard| Right hand raises to rub the back of the neck; head ducks and tilts away; cheek blush flares. |
| `confused_scratch` | Puzzled incomprehension | Left hand scratches temple through hair; head tilted +8°; asymmetric raised eyebrow. |
| `annoyed_crossed` | Dry irritation at silly situation | Arms loosely crossed over chest; weight on one hip; head turned in sideways glance. |
| `smug_lean` | Playful teasing confidence | Weight shifted back, single eyebrow arched high, subtle smirk, one hand gestured playfully. |
| `tired_droop` | Brain-fried exhaustion | Head drooping forward, shoulders sagging heavily, arms hanging limply. |

## 5. Comedic Poses

| Pose ID | Staging Description | Anatomical Keypoints |
|---|---|---|
| `deadpan_freeze` | Iconic 0-motion punchline hold | Absolutely rigid posture facing camera; straight dash mouth; blank stare; holds for 0.6s–1.2s. |
| `awkward_freeze` | Caught doing something ridiculous | Mid-motion lockup: hands frozen awkwardly in space, wide pupils glancing sideways. |
| `disbelief_lean` | "Are you serious right now?" | Torso cranes slowly forward toward the lens, neck extended, eyes narrowed in dry disbelief. |
| `facepalm` | Classic comedy exasperation | Palm pressed flat over eyes/forehead, head angled downward, deep sigh posture. |
| `recoil_horror` | Dramatic comedy shock | Torso snaps far back in frame, arms held up defensively, mouth agape in small 'o'. |
| `defeated_slump` | Complete comedy loss | Shoulders drop completely, chin sinks to chest, tiny dark raincloud doodle overhead. |
| `what_shrug` | Exaggerated baffled shrug | High neck-compressing shoulder shrug, hands spread wide, mouth tilted sideways. |
