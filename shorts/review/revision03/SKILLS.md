# Three ink-edit skills · pose-led recuts

Use [$adb-ink-shorts](../../../.agents/skills/adb-ink-shorts/SKILL.md), [$nemi-ink-shorts](../../../.agents/skills/nemi-ink-shorts/SKILL.md) or [$duo-ink-shorts](../../../.agents/skills/duo-ink-shorts/SKILL.md). The skill supplies cast direction, current supported controls and a scoped starter/render/check helper.

The current canonical examples now contain authored whole-body pose cards, named finite transitions landing at selected music accents, selected face/prop/reaction reframes and original recorded sound accents. Read the example direction and cue map, then create an original idea with a visible cause/payoff.

Follow [workflow](../../godot/V3_WORKFLOW.md), [schema](../../godot/V3_SCHEMA.md) and [reference pass](REFERENCE_PASS.md). Start with `new <short-name>`, adapt the editable template, validate, inspect actual settled poses and transition boundaries, build, check decoded picture/sound/pacing, then watch at real speed before completing review.

Folder: shorts/<adb|nemi|duo>/<short-name>/; movies in render/, evidence in review/, optional unique assets in assets/. Existing r1 source and evidence are retained beside these recuts. New controls extend separate Shorts art/engine only; original storytime rigs/episodes/voices remain protected.
