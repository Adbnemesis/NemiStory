# Isolated Shorts architecture

One standalone Remotion package under `shorts/`, no root config edits. `src/index.ts` registers only Shorts. `adb/compositions` and `nemi/compositions` contain declarative content, each with its own style guide, geometry snapshots, scripts/storyboards/audio source and exports. `shared/` owns deterministic motion/timeline math, beat hooks, camera, caption, transition, background and sound components. Author profiles remain separate. The storytime player, rigs, production schemas and episodes are read-only sources; no new storytime episodes or private doodle player are made.

All authoring uses scene seconds; one frame clock at30fps converts cues to frames. Character motion may explicitly update at15fps; contacts use continuous math. Beat maps are extracted offline, reviewed and stored with source hash and trim/rate. Named events link face/gesture/camera/FX/SFX; no frame-time audio analysis. Existing vector geometry is snapshotted once into generated JSON, not fetched from production at render time. Original rigs and palettes remain untouched.

Shot config describes background, actor pose/expression/gaze/head/body controls, prop mode, caption, camera keys and causal transitions. Sound manifest contains music source/section, narration segments, duck windows, event-linked SFX and measured source hashes. Strict validation rejects missing/unknown fields, assets, duplicate IDs, invalid clocks, out-of-range props and overlap. Rendering validates first and writes under the selected author's `renders/`; proof/contact sheets, logs and audio reports belong under `review/`. A studio safe-area toggle is available. Publish/upload is outside this implementation.

The first music study uses creator-supplied reference audio, not falsely asserted current trend music. Catalog candidates include date/platform/region/evidence/use-count when available. Selection ranks topic fit, usable accents, current trend confidence, duration and lyric meaning; no license gate per user's explicit correction. Metadata retains truthful provenance. New source audio requires a new cue analysis, not stale timings.

Minimum proof content: ADB leg-day visual beat gag; Nemi tiny-edit music gag; ADB engineering dialogue joke; Nemi quick-sketch dialogue joke. These exercise both character profiles, two locations, full bodies/contact, expressive faces, beat drops, voice-aware timing, captions, finite transitions and one exact visual reset. Artistically accepted exports require recorded still/playback review; track current trend and perceptual listening separately where unavailable.
