# ADB / Nemi Shorts grammar

Derived from the four supplied references; creative hypotheses, not retention guarantees.

- Frame1 contains character, action/prop and situation; readable by.5–1s. No intro/fade/logo card.
- Use8–22s only when the joke earns it. Prefer12–18s; don't stretch a good9s loop.
- Choose one focus per thought: setup → want → anticipation → consequence → payoff → reset. Hold when it lets a viewer read or feel a reaction.1–1.8s layout holds are supported by refs01/03; .125–.5s clusters are reserved for a readable escalation like02.
- Treat recorded timestamps as authority. A tempo grid is an editing aid; vocal accents, rests and source drift override it. Cue timestamps in seconds, quantize only once to export frames. Save original source hash, trim offset and all approved corrections.
- Coordinate primary events by named cue: eyes lead2–4f; hand/head anticipate; prop contact + expression + camera landing within1f; impact at landing; optional whoosh starts2–3f early; overshoot settles5–9f. No automatic “everything on every beat.”
- ADB: relaxed pose → one confident detail → still deadpan consequence. Nemi: curious eyes → active hand/tool → expressive disarm → small recovery. No generic continuous body bob.
- Camera: readable medium/full before face punch; protect feet when they carry joke/contact. Slow push may last1–2s. Effects are finite impulses with deterministic decay. Main subject stays inside conservative safe area.
- Character drawing cadence can be15fps with smooth30fps camera. Use continuous motion for contact; choose stepped posing explicitly. Facial switches are discrete, brows/gaze settle. Finite authored blink windows; mouths use reviewed recording intervals, never audio-amplitude phonemes.
- Background establishes an actual location when needed; selective gradient, spotlight, burst or speed lines may replace it at a reaction. No permanent flashing, floating props or distracting detail behind text.
- Caption engine is available for Shorts despite long-form subtitle policy. One hook/punchline block at a time;3–6 readable words, local fonts, high contrast, no UI-edge collision. Word timing only where voice/music meaning justifies it.
- One signature transition per Short plus clean match cuts; object wipe has a causal prop, snap/punch has a reaction reason. Avoid stacking spin/flash/shake/blur.
- Music selection: current trend evidence + topic/lyric meaning + usable beat/drop + duration fit. Popularity cannot repair a mismatched lyric. User's music correction removes license gating from selection. Creator-provided source audio can be used directly. No fabricated track identity, trend claim or source permission status.
- SFX: exact existing root/library recordings with hashes; dry UI ticks forADB, brighter pops/chime forNemi. Vocal memes are commentary, not their dialogue. Preserve approved Aiden/Sohee configuration. Mix gains measured per recording, not blanket assumed dB separation.
- Natural loop: camera/pose/prop/text state at last frame equals first; match audio at a musical phrase boundary separately. A visual loop is not automatically an inaudible audio seam. Semantic restart is valid but label it honestly.
- Review frame1, first second, every second, all event boundaries, payoff and final/first seam. Review encoded audio peaks, cue presence, source coverage and speech clarity. Record still/playback observations and remaining listening limitations. No claims of improved CTR/retention without audience data.
