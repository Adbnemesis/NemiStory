# Topic first, trend checked, audio first

User correction: choose trending tracks that fit the Short's topic and tightly coordinate music/beat/VFX. No copyright/licensing selection gate. Keep honest source identity/hash/provenance; never manufacture “currently trending” evidence. Current demo recordings are from the supplied references, not a claim of October 2026 trend ranking.

For each Short pick target platform/region first (default editorial target: YouTube/Instagram India, not an account assumption). Check the platform's current sounds/Creative Center, store the exact sound ID/URL, region, date and any visible ranking/use-count. Use a 7-day freshness window; stale/unknown trends score no trend bonus. A music title alone is insufficient: slowed/sped versions have different cue maps. Choose topic/lyric fit before popularity; save the reason the selected 8–22s excerpt serves the joke. Examples: ADB's gym confidence vs stairs; Nemi's trust/confidence vs endless undo. Recheck close to posting.

`tools/music_catalog.py` ranks topic overlap, useful cues, energy, duration and fresh trend evidence. Add creator-provided/local audio or actual platform sound metadata to `shared/audio/music-catalog.json`; source assets live in author music/assets, copied into `public/audio/music` by the preparer. No need for separate licensed/royalty-free gates after the user's correction.

Analyze `tools/audio_analyze.py INPUT OUTPUT --start 12.3 --duration 14 --bpm 128 --offset .18` using the project's Python with numpy/scipy. The exported JSON uses **segment-local seconds**, keeps sourceStart and original file hash, pulse candidates/onsets/energy/peaks. Strong beats/drops/choruses are empty until reviewed; spectral peaks are not magically bar downbeats. Review waveform + actual listening, correct tempo/phase and explicit phrase/vocal cues; set `status: editorial-reviewed`. If making a trimmed local WAV, rehash/analyze that exact WAV, set render sourceStart0 and retain original-trim provenance separately.

Audio → segment + cue map → idea → thought beats → storyboard → exact cue links → animation → SFX/mix → export → review. Hooks in `shared/beat-sync` are frame-derived and seek-safe. Music replacement requires new source hash/grid, new storyboard landings and a new render; never keep stale cue times. Pause/drop/word cue can override quantized beats. Render timings round once to 30fps; original source timestamps remain in source maps.
